Comandos

git ini: crea un repositorio

git estatus: revisa el estado actual del repositorio

git add: sube o agrega un archivo a la zona de preparacion o Stage para poder seguir los cambios en el archivo

git commit -m: es para guardar los cambios en el repositorio, debo poner seguido del comando un mensaje que describe los cambios realizados entre comillas

git add "*": agrega todo, si le escribo un .txt por ejemplo, me agregara todos los archivos . txt

git reset: quita archivos que se asubieron al Stage

git log: nos permite revisar un historial de todos los commits que se han hecho hasta el momento en orden cronologico

git pull: descarga la informacion que se ha subido a la rama develop o a la rama donde se este trabajando

git push: se sube el contenido a la rama develop o a la rama donde se este trabajando

git branch: te indica en que rama estamos

git checkout -b: crea una rama y te transporta a ella, lo mismo pero sin la -b te cambia a la rama que quiera ir
